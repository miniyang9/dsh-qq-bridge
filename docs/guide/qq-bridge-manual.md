# QQ 桥接 · 用户手册

> 适用版本：frame v7（2026-10-25）· 面向使用者，不涉及实现细节
> 开发文档另见 `docs/frame/`（需求）、`docs/arch/`（设计）、`docs/build/`（施工与验证）

---

## 1. 这是什么

让**本机的 DeepSeek Harness 在被阻塞时通知你的手机 QQ，并允许你在 QQ 里回答**。

它替你做的事：

- 任务需要批准（删文件、写工作区外、提权）→ 手机收到卡片，你回一条命令决定；
- 任务需要你回答一个问题 → 手机会收到问题卡片，你可以回选项或自由文本；
- 任务卡住了 → 会提醒你（10 分钟、30 分钟各一次）；
- 任务跑完了 → 会发一条"它停了"并附本轮摘要；
- 你可以随时查进度、给它下新指令、唤醒没加载的会话、在已知工作区里新建会话。

它**不**替你做的事：

- 不会替你批准任何东西（你不回，它就一直等）；
- 不会在你看不到的地方改你的代码——所有写操作都是你让它做的那个任务本身在做，桥接只负责传递；
- 不会自己建新工作区、不会在未知路径起任务。

---

## 2. 前置条件

| 项 | 说明 |
|---|---|
| Windows | 本机运行，插件装在 DSH 里 |
| DeepSeek Harness | 桌面版，能正常打开会话 |
| QQ 机器人 | 在 [QQ 开放平台](https://q.qq.com/) 注册，拿到 `AppID`、`AppSecret` |
| 白名单 openid | 只有这个 QQ 号能与机器人对话（其他人的消息一律不回应） |

---

## 3. 安装

```powershell
dsh plugin --profile desktop add C:\Project\WatchDog
```

然后在该 profile 的 `cordis.patch.yml` 里追加：

```yaml
- id: qq-bridge
  name: dsh-qq-bridge
  config:
    transport:
      appId: '<你的 AppID>'
      appSecret: '<你的 AppSecret>'
      allowlist: ['<你的 openid>']
```

**重启 DSH**（完全退出再启动）。停在这里不算装好——插件只在启动时加载一次。

---

## 4. 第一次验证

在 QQ 里给机器人发：

```
/list
```

应当收到带序号的会话列表。收到即表示链路通。

如果没有任何回复，按第 10 节排查。

---

## 5. 列表里的状态是什么意思

| 状态 | 含义 | 能做什么 |
|---|---|---|
| **运行中** | 会话正在跑（turn 未结束） | 不能 `/say`（会打乱它），可以 `/progress` 看 |
| **空闲** | 已加载、当前没在跑 | 可以 `/say`、`/why` |
| **未加载** | 磁盘上有，但进程里没有它 | 先 `/wake`，不能 `/say` |

`已绑定` 是另一个标记：表示你最近一次 `/use`、`/wake`、`/new` 选中的是它。

> 重启 DSH 后所有会话都会显示"未加载"——这是正常的，用 `/wake` 挂回来即可。

## 6. 命令手册

会话有两个标识：**序号**（`/list` 里的 1、2、3，会随新建/唤醒漂移）和**短 id**（如 `dd94c5`，永远指向同一个会话）。
命令两种都接受；**建议用短 id**。

### 6.1 看

| 命令 | 作用 |
|---|---|
| `/list` | 全部任务（跨工作区，不含归档与咨询会话） |
| `/progress [id\|序号]` | 当前状态、待答请求数、最近 5 条事件 |
| `/doctor` | 已移除 |

### 6.2 答复（最常用）

| 命令 | 作用 |
|---|---|
| `/ans <id> 1` | 审批：选第 1 项（批准） |
| `/ans <id> 2` | 审批：选第 2 项（拒绝） |
| `/ans <id> <文本>` | 提问：用自由文本回答 |
| `/yes <id>` | 批准**被标注**的（不可逆）请求——这类只认 `/yes` |
| `/no <id>` | 拒绝（两档通用） |

这里的 `<id>` 是**卡片上的 `wp-N`**（请求 id），不是会话短 id。

- 卡片上会直接写出该用哪条命令，照着发即可；
- 多打几个字没关系（`/ans wp-3 1 发送` 也按选 1 处理）；
- 已被处理过的请求会明确告诉你"已被采纳/已作废"，不会静默生效。

### 6.3 控制

| 命令 | 作用 |
|---|---|
| `/say <id\|序号> <文本>` | 给会话发指令（会先回显，再要你确认） |
| `/wake <id\|序号>` | 把未加载的会话挂回进程 |
| `/use <id\|序号>` | 绑定会话（之后的 `/say` 默认发给它） |
| `/new [工作区序号]` | 在**已知工作区**新建会话（每工作区每天 10 个） |

`/say` 的流程是两步的：

```
/say dd94c5 把测试跑一遍
→ [wp-7] 将要发送：把测试跑一遍
  上次停在：…
  改：/ans wp-7 1 发送 ｜ /ans wp-7 2 取消
/ans wp-7 1
→ 已发送：把测试跑一遍
  （followup｜事件 12→14）跑完我会把回答带回来一条。
```

跑完后会收到：

```
会话 dd94c5 回复：<它这一轮最后说的第一句>
```

### 6.4 咨询（问"它为什么停"）

| 命令 | 作用 |
|---|---|
| `/why <id\|序号> <问题>` | 针对该任务起一条**咨询会话**，替你去问现场 |
| `/done <id\|序号>` | 结束咨询（会自动归档该咨询会话） |

- 可以连续追问，同一条咨询会话会记住上下文；
- 5 分钟不追问会自动结束；
- 咨询会话能读写文件（它会去看代码/日志），每次改动都会在回话里列出并进审计；
- 咨询会话**不出现在 `/list` 里**，用完 5 分钟或 `/done` 后归档。

### 6.5 不带 `/` 的消息

一律只回一条状态提示，不会执行任何动作。这是刻意的（避免手滑把"1"当成批准）。

---

## 7. 它会在什么时候主动找你

| 时机 | 你会收到 |
|---|---|
| 需要批准 / 需要回答 | 卡片（多个同时到达时合并成一条，最多等 1.5 秒） |
| 一轮跑完 | `[会话标题 · 短id]` + `本轮 N 分钟：<摘要>` + 唤行动词 |
| 10 分钟没有新输出 | 停滞提醒（同一条只发一次） |
| 30 分钟仍没有 | 升级为"可能卡住了"，并建议 `/why` |
| 连接断过 | "我重连过（连接曾无响应）" |
| 断网期间有消息没送出 | 恢复后一条摘要："断网期间有 N 条没送达" |
| 你关掉 DSH | "我下班了（桥接退出）" |

所有通知总长控制在 300 字内，且**每轮只发一条**，不会刷屏。

---

## 8. 安全模型

- **只有白名单里的 QQ 号有效**，其他人发的消息完全不回应（连"拒绝"都不回）；
- **批准不会被代劳**：你不回，任务就一直等；
- **每个决定都进审计**（`audit.jsonl`）：谁、什么时候、当时看到的卡片原文、批了什么，保留 180 天；
- **QQ 号被盗 = 隐私与控制权同时丢失**，这一点没有技术手段能弥补——请给 QQ 开二次验证。

## 10. 故障排查

| 你看到的 | 含义 | 怎么办 |
|---|---|---|
| `参数「x」无效：找不到这个会话` | 短 id 打错或会话已删除 | `/list` 对照短 id |
| `xxx 没加载：先 /wake` | 会话不在进程里 | `/wake <短id>` |
| `它正在跑（turn 还没结束）` | 不能打断 | 等它停，或先 `/progress` |
| `拿不到会话服务` | DSH 版本/服务名变了 | 记下原文反馈给维护者 |
| `唤醒失败：<原因>` | 会话损坏或被占用 | 见下一条 |
| `stored log is corrupt: title messageSeqs requires an array` | 早期版本写坏了会话日志 | 运行 `tools\repair-title.mjs` 修复（会先备份） |
| `这条超时没等到你…` | 长时间未处理 | 重新发一次命令 |
| 完全收不到回复 | 通道没连上或白名单不符 | 重启 DSH 看日志；确认 openid |

---

## 11. 卸载 / 回滚

```powershell
dsh plugin --profile desktop remove dsh-qq-bridge
```

并删除 `cordis.patch.yml` 里那段 `- id: qq-bridge`。重启后审批会回到 DSH 自己的弹窗。

---

## 12. 已知限制

- **QQ 单聊被动窗口 60 分钟、每条消息最多回 4 次**：超过 55 分钟的通知会改走主动消息；
- **主动消息可能被你关掉**（QQ 客户端设置），关了之后只能靠被动窗口；
- **会话标题**：桥接新建的会话先叫 `QQ`，第一句话进来后会变成 `QQ <那句话>`（重名可接受，故意不拼 id）；
- **未真机验证**：时延（≤10 秒承诺）、每日通知预算、8 天日志轮转、断电/睡眠恢复。这些在本机测试通过，但没有经过长期真机运行。
